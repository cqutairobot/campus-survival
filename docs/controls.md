# v4.0.0 操作与调试

WASD／方向键移动；手机在画布空白处按住拖动浮动摇杆。Space／Q 或右下按钮释放大招，忽略按键连发；右手大招触点与左手摇杆独立。E 按住地标互动，移动、受伤、松手中断不扣次数。手机操作目标至少 44px，大招按横竖屏约 76–84px，长名称使用较宽按钮。Esc／P 暂停，后台／失焦自动暂停，回来手动继续；旋转与后台清空全部输入，单个 pointercancel 只清理对应触点。

升级和奖励点击或按 1／2／3；风险契约可放弃。地图、图鉴和设置打开时暂停；手机「展开构筑」显示完整武器／被动栏。融合奖励会列明两件材料、品质、所得产物与腾槽。

地标规则、成就条件和全部数值见 [v3 数值](v3-balance.md)。主菜单每日挑战统一 Lv.3 天赋并借用全内容，每天北京时间零点更新；设置修改本地昵称。普通玩法解锁在结算后、下一局生效。

## `?debug=1`

仅打开或观察调试面板不影响正常结算。修改玩法的指令立即将本局标为练习局，禁写绩点、成就和每日榜；正常大招、互动、暂停、奖励选择、主动结束属于普通指令。保留图鉴发现行为。

新增功能：

- 敌人 ID、normal／elite／miniBoss／boss／bossAdd、六词条任意组合；精英必掉箱、两种小 Boss、护盾与分裂链预设。
- 大招设满、正常释放、能量来源与各类别控制抗性。
- 六融合准备材料、当前候选与已消耗材料，打开正常宝箱流程；旧快速进化仍保留。
- 七种任意拾取、契约台、六事件切换、六地标传送、本局临时解锁内容。锁区传送须先临时解锁；只改变本局地图、导航与内容池。
- 指定日期每日预览：规则版本、固定角色、种子；八条玩法随机流状态只读显示。正式每日种子不由 URL seed 覆盖。
- 分数基础／时间／风险明细、平均诅咒持有、母体奖励权重、榜资格、普通怪命中直方图、首伤至死亡中位／P90、护盾与过量伤害。
- 导出会话 JSON（规则、构筑、奖励、控制、随机流、新指标）、性能摘要、新格式回放，检查旧回放版本。

保留原有跳周、Boss、经验、授予五级与进化、无敌、伤害倍率、随机流、单步、磁铁／炸弹、狂热、连杀、碰撞网格、导航和手动密度预设。500／800／1200 按钮仅保留为手动工具，本轮未运行这些预设，也不在默认测试中调用。

最快体验融合：本局临时解锁 → 选择配方 → 准备融合材料 → 正常宝箱流程 → 选择融合 → 快速揭晓 → 继续。最快体验地标：临时解锁 → 选择地标 → 传送 → 按住 E／互动按钮。生成契约台后走近，再互动进入三选一／放弃。


## v4 反馈与声音

设置分别调整镜头震动、闪白/滤镜和局部表现停顿（0–1）。减少动态效果关闭局部停顿、形变、视觉后坐、屏震、推拉、扭曲、移动粒子和残影，数字及选中状态静态显示；危险提示、轮廓与声音保留，原有逻辑停顿不改。各类面板和长卡片可垂直滚动，横竖屏及四边安全区均适配。

画质由玩家手动选择，旧 auto 按高处理。音量分为主音量、音乐、战斗与 UI；动态音乐和重击压低可分别关闭。播放设备预设默认自动：触屏手机优先手机外放，其他标准；连接耳机可手动改为标准。设置中可查看逐文件素材许可。

## 三个隔离实验室

仅 `?debug=1` 显示入口：菜单右下「表现调试实验室」；战斗中展开左侧虫子按钮 →「打开表现调试实验室」，当前战斗暂停。关闭后手动恢复。

- **打击感**：正式渲染器的隔离暂停场景，普通、暴击、击杀、精英、小 Boss、Boss、玩家受伤；方向、材质、事件密度；闪白、形变、后坐、trauma、停顿和滤镜参数。勾选「关闭 v4 表现层（A/B）」比较，并查看 generation / 效果绑定。
- **音频**：材质和普通/暴击/精英，起音/主体/尾音，密集事件、声部/淘汰统计与 ducking 曲线；五首成品曲独听、输出预设、加载/解码失败回退。
- **界面动效**：全部 20 类界面、四品质、长中文、多位数字、完整/锁定/空状态、缺图及减少动态效果；手机、iPad、桌面和超宽 CSS 像素预览，重播动画。

三个实验室均有「导出…参数 JSON」。它们使用独立 iframe 和无真实 Storage 的内存仓库，不读取或写入正式存档、不增加每日挑战次数。内部测试动作不会影响父页面战斗资格；旧玩法调试命令仍遵守练习局规则。
