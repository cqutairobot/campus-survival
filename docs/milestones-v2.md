## 与计划的具体区别

- 所有计划中的包版本均存在，无需替换。类型依赖采用实际可用的精确版本；Vite 8 的 Rolldown 使用函数形式 `manualChunks`。
- 为方便维护，职责相邻的小模块合并为文件，未机械创建计划中的所有空目录。
- 数字使用预烘焙数字纹理组成，普通敌人白闪使用加载阶段生成的白色纹理；视觉粒子使用原生 v8 `ParticleContainer`。
- 实体池保留约 25% 余量：敌人/玩家弹丸/掉落各 2560，敌弹 1280，区域 320。Boss 入场撤退普通敌人后分配实体，不额外占用普通刷怪预算。
- 画面采用奶油色与草木绿，危险使用珊瑚色；后处理集中在效果层，低档保留几何环和危险预警。
- 关卡、经验、武器、进化、角色、天赋按计划基线；自然通关回归使用已有的满级局外天赋，没有调试无敌或伤害加成。这验证可通关，并不代表新存档首局一定通关。
- 核心逻辑没有后端、网络 AI、云存档或中途续玩。运行时资源全部来自打包产物，音频在用户开局操作后本地合成。

## 测量的边界

CPU 模拟、无 GPU 浏览器渲染与真实 iPhone 12 / Pixel 6 是不同验收层次。模拟耗时和浏览器模拟布局不能替代真机 FPS、发热、GPU 内存、真实音频解锁与后台行为验证。最终测量见 `verification.md` 和 JSON 报告。
