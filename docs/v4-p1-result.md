- 全界面统一为深墨蓝、青玉、香槟金：六角色立绘/头像及集中属性、按原 parent 关系连线的天赋、八类图鉴与材料公式、14 成就、每日规则与本地榜、设置、暂停、结算、宝箱及契约/融合/进化。
- 137 张源 PNG 全部处理并绑定；168 WebP、125 PNG 回退。六角色精灵紧裁并加细描边，按约 64px 显示且有脚底阴影。竖屏菜单使用专用 `menu-campus-portrait.png`。草地、铺装和金属贴图、树、长椅、花坛与全部建筑/地标已接入。
- 建筑保持图片比例，矩形底板精确使用原碰撞矩形，图像底边贴齐；地标/props 仅装饰。资源按 shell、items、battle、boss、详情、结算等包按需加载，全局六请求并发、重试、PNG 与几何/SVG 回退；退出释放共享纹理引用和局部快照。
- 全武器、进化、融合、大招、敌人和事件接入材质音效。物理 Foley 与设计尾音区分标注；实际声部上限 48、类别优先级、35ms 合并与统一 duck 保持固定规则。

- 全 25 敌人有明确材质死亡映射：纸片、硬质碎片、晶片与能量收缩溶解；精英保留短轮廓，Boss 在原死亡阶段内完成。全武器/进化/融合/大招有反馈映射与层级，独立于模拟与玩法随机流。
- 逐图/逐音频署名、许可和原始 AI 元数据已同步到 `docs/credits.md`、`src/assets/attributions.json` 与 `public/licenses/`。

## 已知限制与 P2 建议

- 6 张 P0 原图缺少生成工具、日期与提示词；其余 131 张严格按 metadata.json 记录。AI 原图没有另附独立开源许可，因此如实标为用户提供素材，没有推断为 CC0。

- P2 建议继续做真机与极端屏幕比例的细节打磨、中低档/减少动态效果精修、混音试听及完整调试实验室；如再压缩资源，可评估图集/KTX2。这些未在本次扩展实施。
