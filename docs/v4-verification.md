## 规则冻结核对

v3 备份版本为 3.0.0，备份不存在被排除的五类目录。与备份逐字节比较，武器、敌人、波次、每日规则、成长规则、武器系统、伤害、死亡队列、固定循环、计分文件完全一致。核心引擎只追加只读表现元数据与实际回复量事件；新增的三秒固定输入测试证明消费反馈不改变伤害、掉落、随机流或结果摘要。

## 两个 bug

- 冲击波：不再使用归一化 `(0.5, 0.5)`。`eventPixelPosition()` 使用事件世界坐标、场景平移、缩放和旋转，得到 viewport/filterArea 内的实际 CSS 像素；冲击波与径向模糊共用事件中心，世界 filterArea 固定为画布范围。HUD、敌弹、危险提示不进入滤镜链。
- 音乐压低：删除旧的两条 `.708` 计算路径，所有音乐音量经 `musicGain()` 统一计算；重叠事件取最深的包络，master/pause/crossfade/duck 各乘一次。单元测试验证重叠、关闭开关、crossfade、失败回退、异步取消和销毁。

## 已知限制 / P1 补图

- 均衡型战斗精灵来自立绘缩小，头像来自头肩裁切；不是专用俯视绘制。菜单由 1024×576 放大，细节受原图限制。
- 其余角色、武器和世界物件保留原美术/几何回退；全界面覆盖、完整 A/B 实验室与混音精修属于后续里程碑。
- 自动检查不替代主观试听。音乐整曲循环接缝、手机外放响度及非 Chromium 平台仍需人工验收；没有为此增加多浏览器测试。
- 用户 AI 源没有工具、生成日期和完整提示词元数据，署名清单如实标为未提供，并保留源文件 SHA-256。

按原计划编号的完整素材清单见 [P1 待补美术](v4-p1-art-needed.md)。
