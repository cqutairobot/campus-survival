# 《校园生存》4.0.0 设计与表现约定

v4 已完成 P0、P1、P2，只升级表现。P2 对应 `/workspace/game_v4_plan.md` §13 的统一与收尾；不增加玩法、内容、数值，不引入 KTX2/Basis。

## 冻结边界与兼容

固定 60Hz、原逻辑停顿预算、角色和武器数值、AI、碰撞、真实击退、掉落、奖励 token、评分和每日随机流保持 v3。只读表现事件携带 slot、generation、材质、方向和死亡快照。表现随机源不消耗玩法随机流。

`package.json`、锁文件项目版本和 `CONTENT_VERSION` 均为 **4.0.0**；存档 schema 仍为 3，继续使用 `campus-survival.save.v3`。v2、v3、P0、P1 仅补缺失设置，新加 `audioPreset='auto'`，保留显式 false、0、静音和中低档；迁移纯函数、幂等，保留旧键、损坏档备份与未来 schema 保护。新档屏震、闪白仍为 **0.8**。

## 视觉系统

`src/design/tokens.ts` 同时导出 CSS token 和 Pixi 颜色。深墨蓝界面、青玉与香槟金点缀，校园保持明亮绘本地面。六角色立绘/头像/精灵、25 敌人、全部已有物品、建筑、地标和事件均由统一 bindings 绑定；八类图鉴、角色、天赋、成就、每日、地图、设置、暂停、选卡、宝箱、融合/契约及结算共享材质。

美术保持比例，建筑底座严格对齐原碰撞矩形，地标、树与 props 不增加碰撞。字体为自托管 Campus Sans、Campus Title、Campus Digits；缺字走系统字体，字体失败最多等待 1.8 秒。

## 手机与布局

`p2.css` 统一 safe-area-inset 的四边变量、44px 操作目标、可伸缩网格和长中文/数字换行。覆盖 360×640 至 430×932、手机横屏、iPad 和超宽桌面。HUD 用网格安排生命/进度/地图/暂停，信息区和主要操作区分开排列，极端长信息可独立滚动；低屏横屏保留独立大招与互动；完整 6+6 构筑可展开。调试入口缩在侧边，避免覆盖底部战斗操作。

面板、选卡、宝箱、暂停、结算和图鉴在内容较长时滚动；面板标题/关闭按钮固定在滚动内容外。横屏选卡取消旧的绝对定位脚注，属性和确认区不重叠。多位击杀数缩字号，生命数分组换行，长技能名使用较宽按钮。竖屏每日挑战仍保持完整 1280×800 逻辑视野。

## 动态效果

`FeedbackDirector` 协调 EntityFeedback、PresentationClock、CameraRig、PostFX、DeathFX。受击以 slot+generation 绑定，近身视觉偏移最多 2px；新增局部停顿不会暂停模拟。Trauma、推镜与事件像素中心保持 P1 的高档强度。

关闭 `motion` 后立即清除局部停顿、形变、后坐、屏震、推镜、扭曲、粒子移动与移动残影；伤害数字、结算数字、伤害条和选中状态静态显示。CSS 动画/过渡统一关闭，GSAP 作用域在开关改变或卸载时 revert，防止保留半透明和中间缩放。文字、状态轮廓、声音、敌弹、危险区域和低血量静态提示继续显示。原有逻辑停顿预算不变。

## 调试与释放

`?debug=1` 的三个实验室采用独立 iframe 文档和**无 Storage 的内存仓库**，不读取/写入真实存档，不启动每日挑战。打击感使用正式 GameHost 的隔离暂停场景；界面使用完整/锁定/空 fixture，不推进真实引擎。三者都可导出参数 JSON。普通修改玩法的旧调试指令继续标为练习局。

场景退出清理 RAF、ResizeObserver、输入监听、预览定时器、死亡子纹理、程序纹理、滤镜和纹理租约；资源卸载与重新获取串行协调，共享图集有引用时不卸载。App 音频库有固定缓存，退出清掉会话声部/环境声，音乐最多一首淡出加一首淡入。GSAP 作用域随界面卸载释放。具体证据见 [验收](v4-verification.md)。
