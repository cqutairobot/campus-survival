## 唯一 Chromium 冒烟

同一条用例依次覆盖：

1. 注入旧 schema v2，验证迁移后的绩点、已购角色、发现、进化、天赋和已结算 ID。
2. 正常开局、键盘移动，在同一 Chromium 窗口改为手机尺寸，左手摇杆＋右手大招；取消右手触点不清空左手输入。
3. 保持高画质，检查粒子预算 32768；使用标为练习局的调试准备生成精英，击杀恰好一箱，经正常宝箱选择与揭晓完成校园剑阵融合。
4. 正常处理精英经验排队的选卡，生成并互动契约台，完成一组自选契约。
5. 用普通 Esc 暂停并主动结算，验证练习局不发绩点、不推进成就，图鉴发现可保留；返回菜单释放会话和 canvas。
6. 另开独立、未修改玩法的正式每日局，验证固定种子不受 URL seed=999 覆盖、逻辑视域 1280×800，正常主动结束，写入本地记录且不发普通绩点。
7. 返回菜单、刷新，验证本地榜仍有记录，再关闭面板；窗口调试会话为空、canvas 为零。

最终用例断言页面错误为零，并额外断言 Pixi BindGroup 与 GSAP 空目标警告为零。运行日志唯一 Node 提示为测试运行器同时设置 NO_COLOR 与 FORCE_COLOR，不属于游戏错误。

调试只用于普通冒烟局的内容准备；正式每日写榜段不调用改玩法指令、无无敌、无跳周、无加能量或改存档结算。仅跑一条用例，修复过程中针对失败的同一条冒烟重跑，没有扩展浏览器或压力场景。

初期失败来自测试未等待真实奖励 token 提交／未处理精英经验引发的正常选卡，修复测试等待并保留游戏奖励。另修复窗口缩放时滤镜临时纹理被回收而仍有着色器引用的问题：每次渲染后、缩放与销毁前解除临时纹理绑定；保留全部滤镜与预算。升级选卡直接在固定步结束后暂停，移除旧的缩放 dt 过渡，保证规则仍为固定 60Hz。

## 画质、依赖与交付

高／中／低粒子 32768／8192／1024，拖尾 32／12／4，残影 5／2／0；大招与融合高潮 1600／550／100。旧 auto 按高档解析，无自动降档或半帧渲染。仅活跃粒子提交渲染，不降低容量、击杀碎片或高潮数量。当前容器为 SwiftShader 软件渲染，因此不将其 FPS 视为真实 GPU 或手机性能结果。

## 偏差与已知边界

- 没有功能范围删减；八项推荐设计均实现。按职责复用现有模块，未机械照抄计划建议的所有文件名。
- 模型工坊的引导时长原计划未规定，采用 .5 秒；其收益、冷却和次数保持计划值。高档高潮粒子选取计划区间内 1600。
- 没有发现阻塞试玩的问题。按用户约定未做真实 GPU／手机热机、多浏览器或完整学期长局验证；当前数值是 v3 首轮基线，短定点只说明对应参考场景。
- 旧游戏 v2 回放不保证在 v3 复现，按计划明确提示；新回放格式 v2 记录规则与开局快照。存储不可用时使用内存并允许导出，不提供战斗中途续玩。
