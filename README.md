# 校园生存 v3

中文校园题材俯视角生存游戏：在北建大艺术化校园里度过 22 周，自动攻击，手动走位、释放大招和选择构筑。纯前端，无后端、账号、CDN 或联网排行榜；图形、图标和音频均在本地程序化生成。

## 开始试玩

```bash
cd /workspace/campus-survival
npm ci                # 已有 node_modules 时可跳过
npm run dev
```

打开终端输出的地址。同一局域网手机可打开 Network 地址。构建后的 `dist/` 可直接托管到静态 HTTP(S) 服务，支持子目录。

- **直接体验完整新内容：** 主菜单点「每日挑战 · 本地榜」，当天固定角色、八项 Lv.3 天赋，22 武器、16 被动、六区全部借用开放；不改普通模式养成。
- **普通模式：** 旧 16 武器、旧 12 被动保持可用，丁字尺、液氮和四个新被动默认开放。其余新武器、两名新角色和三区域随成就解锁，下一局生效。
- **快速体验：** 打开 `/?debug=1`；设满大招、跳至第 9 周、准备融合材料、生成精英、进入正常宝箱选择；还能生成契约台、任意拾取、事件、传送地标。先点「本局临时解锁完整内容」可打开全部区域。本局修改玩法后为练习局，不写绩点、成就或榜单，图鉴发现保留。

## 操作

| 操作 | 桌面 | 手机 |
| --- | --- | --- |
| 移动 | WASD／方向键 | 战斗空白处按住拖动浮动摇杆 |
| 主动大招 | Space／Q，按住不连发 | 右下独立大招按钮，可与左手摇杆同时使用 |
| 地标／契约互动 | 按住 E | 靠近后出现独立互动按钮 |
| 升级／奖励 | 点击，或 1／2／3 | 点击卡片，契约可放弃 |
| 暂停 | Esc／P／右上按钮 | 右上按钮 |
| 地图／图鉴 | HUD 按钮，打开时暂停 | 同左；「展开构筑」查看完整 6+6 槽 |

失焦、后台和旋转清空输入；后台自动暂停，回来手动继续。触点取消只清理对应触点。手机竖屏每日战斗完整显示 1280×800 逻辑视域，其余空间容纳 HUD。

## v3 内容

- **22 武器、16 被动、22 进化、6 融合。** 新增丁字尺、蓝图炮台、羽毛球、经纬仪、液氮、模型砖；护甲、吸附、大招充能、暴伤四个新被动。6 武器＋6 被动、基础五级、四档品质。
- **12 普通怪、随机精英、两只小 Boss、三场大考。** 新增扇形远射、直线冲锋、单代分裂、自爆、召唤、盾卫和加速领队。精英六种词条，不重复组合，每只必掉一箱；11／18 周出现小 Boss，教学继续，遇大考边界先完成小 Boss。
- **六名角色各一手动大招。** 开局 60／上限 240 能量，最短间隔 30 战斗秒；与自动狂热独立。建筑型、实验型由成就免费解锁，旧角色购买状态保留。
- **七种即时拾取。** 红牛、磁铁、炸弹、冻结时钟、应急护盾、浓缩咖啡、灵感便签，另有经验和宝箱。满血红牛留地面；炸弹清除范围内敌弹、预警、危险区并结清普通分裂链奖励。
- **六地标、六事件、六组自选风险契约。** 契约台在 4／11／18 周第 4 秒出现，保留 60 战斗秒，三选一或放弃，本局最多三组，不占技能槽。收益与诅咒一起生效，按持有时长给予风险奖励。
- **14 项成就、八类图鉴、内容解锁、每日挑战、本地榜。** 发现与解锁分开保存，成就在正常结算提交。

普通怪生命第 6 周后改为缓增长，第 22 周 3.2 倍，接触伤害上限 1.9 倍，速度成长上限 1.28 倍，不根据玩家输出加血。压力来自敌群数量、包抄、弹幕与支援目标。保留 22×40 秒教学及第 8／16／22 周大考加时。

## 进化与融合

武器 Lv.5＋对应被动至少 Lv.1 后，可在宝箱选择进化。精英／小 Boss／大 Boss 箱普通强化分别为 1／2／3 份；也可换一次进化或融合。无法强化时每份回复 15 HP，满血转为结算绩点＋1。结果先提交再展示，默认 .6 秒揭晓，可跳过。

融合从第 9 周开放：两件指定 Lv.5 材料（允许已进化）消耗后换一件，释放一个武器槽，品质取较高值，被动保留，每局最多两次。材料本局不再进选卡池；材料弹丸、召唤物和持续伤害在提交时停止。

| 材料 | 融合 |
| --- | --- |
| 笔记本飞刀＋丁字尺 | 校园剑阵 |
| Codex 助手＋蓝图炮台 | 智慧校园中枢 |
| 订书机＋羽毛球 | 高速装订机 |
| 激光笔＋经纬仪 | 天穹测绘阵 |
| 咖啡＋液氮 | 冰火实验场 |
| 模型砖＋圆规地雷 | 结构爆破阵 |

完整五级参数、22 条进化、掉落、逐周分布、控制抗性、区域和成就表见 [v3 数值](docs/v3-balance.md)，游戏图鉴使用同一份内容定义。

## 每日挑战

北京时间 00:00 更新，开始日期锁定，跨午夜仍归入开始日期。每日固定角色、初始武器、规则、种子、统一 Lv.3 天赋和完整内容池；六套模板，有效战斗上限 1200 秒，可无限重试。

分数来自完成周、普通母体权重、精英、小 Boss、大 Boss、通关与通关用时，再按平均诅咒层数加成。召唤体不计分，分裂链权重守恒。暂停、选卡、宝箱、演出不计成绩时间，时停继续计时。每日期／规则版本保留前十名、最近 30 天，仅存本机；昵称可在设置中修改。URL `seed` 不覆盖正式每日种子。每日不给普通绩点，只推进每日成就。

## 存档与回退

启动自动按 v3 主档→v3 备份→v2 主档→旧备份→v1 主档恢复并迁移到 schema v3。保留有效绩点、角色、天赋、发现、设置和已结算 ID，旧档原文不删除，v3 不回写旧键。只保存局外进度，不保存战斗中途状态。设置面板可导入 v1／v2／v3、导出 v3；未来未知 schema 拒绝导入，存储不可用时可继续内存游玩并导出。

实现前的 v2 完整备份位于 `/workspace/campus-survival-v2-backup/`（排除 `node_modules`、`dist`）。详细键名、校验、成就回填与异常行为见 [迁移说明](docs/v3-migration.md)。

## 画质与声音

新档默认高档，旧 `auto` 按高档解析；中、低档由玩家主动选择，无按帧率自动降档或半帧渲染。

| 项目 | 高 | 中 | 低 |
| --- | --- | --- | --- |
| 粒子容量 | 32768 | 8192 | 1024 |
| 拖尾历史 | 32 | 12 | 4 |
| 残影层数／时长 | 5／.22 秒 | 2／.12 秒 | 0 |
| 普通击杀碎片 | 36—48 | 16—24 | 6—8 |
| 精英死亡 | 240 | 100 | 24 |
| 大招／融合高潮粒子 | 1600 | 550 | 100 |
| Bloom | 1.6，高潮 2.2 | 1.0 | 关闭 |
| 冲击波幅度 | 18 | 9 | 几何环 |

共享材质图集包含纸、键帽、代码、冰晶、玻璃、金属、蓝图和砖块；粒子仅提交活跃实例，容量及数量预算保持完整。危险轮廓、敌弹、玩家外轮廓独立置顶，低档同样保留。支持闪光、震屏、残影、减少动态效果和触觉设置。

音效由 ZzFX 合成、Howler 播放，约 50ms 聚合，最多 23 音效声部＋1 音乐，高潮音乐约 −3dB；新增六武器材质音色、精英提示、大招主题、雨声、停电低通和考试节奏。触觉能力检测并至少 200ms 限频。
