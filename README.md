# 校园生存 v5

中文校园题材俯视角生存游戏：第一学期 22 周，普通毕业后开放第二学期 24 周。攻击自动瞄准，手动走位、释放大招并选择构筑。纯前端，无账号、后端或联网排行榜；存档与榜单保存在此设备。

产品版本以 [package.json](package.json) 为唯一来源，菜单、发布元信息和构建后的 HTML 读取同一版本。当前存档 schema 4，兼容 schema 1–4 和历代 fixtures；第一学期旧基线、旧成绩与未知评级保持原义。

## 两个学期

| 项目 | 第一学期 | 第二学期 |
| --- | --- | --- |
| 教学日历 | 22×40 秒 | 24×40 秒 |
| 主线考核 | 第 8 / 16 / 22 周 | 第 8 / 16 / 24 周 |
| 每日有效战斗上限 | 1200 秒 | 1500 秒 |
| 武器 / 被动 / 进化 / 融合目录 | 22 / 16 / 22 / 6 | 26 / 20 / 26 / 9 |
| 区域 | 原校园六区 | 六区加智慧教学楼外场、产教联合实验园、学生成果展廊 |
| 收藏分母 | 123 | 新增 53，合计唯一 176 |

Boss 战另计加时，暂停、选卡、奖励和演出不消耗战斗时间；每日到达上限即结束，同帧击杀不能换成胜利。主线三考的最终奖励需要确认。普通毕业资格、评级和每日记录按学期隔离；绩点、角色、天赋、设置和共有收藏共享。

第二学期开学继承三选一：15 点盾（60 战斗秒）、前 120 战斗秒经验 +8%，或以合法 Lv.1 普通武器替换初始课题。开局后锁定，菜单后续选择不改本局。图鉴与地图读取当前活动学期与开局开放区域。

## 本地试玩

环境已有 node_modules 时直接运行；需要恢复依赖时使用现有 lockfile，不升级版本。

```bash
npm run build
node node_modules/vite/bin/vite.js preview --host 0.0.0.0 > /tmp/campus-preview.log 2>&1 &
campus_preview_pid=$!
# 结束试玩后
kill "$campus_preview_pid"
```

开发模式可用同样的后台方式运行 `node node_modules/vite/bin/vite.js --host 0.0.0.0`，结束时关闭对应进程。同一局域网手机可访问终端给出的 Network 地址，生产 dist 可托管到静态 HTTP(S) 服务并支持子目录。

主菜单选择学期；第一学期普通毕业证据即可进入第二学期，不要求全收集。每日挑战借用固定角色、全内容池与八项 Lv.3 天赋，不改变普通养成。`/?debug=1` 的练习操作会取消绩点、成就、评级和榜单资格，图鉴发现仍可保留。

## 操作

| 操作 | 桌面 | 手机 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 战斗空白处拖动摇杆 |
| 大招 | Space / Q | 右下独立按钮，可与左手移动同时使用 |
| 第一学期互动 | 按住 E 引导 | 按住独立互动按钮 |
| 第二学期互动 | 点按 E，静止完成读条 | 点按独立按钮，静止完成读条；移动或受伤中断 |
| 升级 / 奖励 | 点击或 1 / 2 / 3 | 点击卡片，契约可放弃 |
| 暂停 | Esc / P / 暂停按钮 | 暂停按钮 |
| 面板 | Tab / Shift+Tab 切焦点，Esc 关闭上层 | 地图 / 图鉴按钮；低高度横屏可展开构筑 |
| 缩放 | 浏览器缩放 | 菜单、指南和面板可双指捏合缩放；画布拖动控制移动 |

失焦、后台和旋转会清空输入；后台自动暂停，回来手动继续。取消触点只清理对应触点。横竖屏均可玩；固定 60Hz 模拟与完整视觉效果保持。

最多 6 武器 + 6 被动 + 3 遗物。武器 Lv.5 + 对应被动 Lv.1 可在宝箱选择进化；精英 / 小 Boss / 主线 Boss 箱普通强化为 1 / 2 / 3 份，也可换一次进化或融合。第 9 周起两件指定 Lv.5 材料可融合，每局两次，释放一个槽；补槽仍需选卡和升级。范围专精可能牺牲单体输出，卡面会说明；导师数量是表现印章，每轮每目标一次命中。

第一学期使用宝箱揭晓动画，快速揭晓设置仅控制该学期的 .6 秒 / 2 秒展示；第二学期奖励提交后点“继续”，进化演出再确认一次，快速揭晓设置不影响这套界面。过期奖励指令不能关闭下一箱。

## 每日与存档

北京时间零点切日，日期 / 学期 / 规则版本 / 种子在开局固定，跨午夜仍归开局日；URL seed 不覆盖正式每日。每日不发普通绩点，练习 / 调试也不发收益，重复结算全局去重。

当前规则每学期保留最近 30 个日期、每日前十；历史版本成绩永久保留原分，可切换日期和版本查看。最佳评级按规则 / 评级版本分组，历史未知不回算。

只保存局外进度。schema 1–3 原文归档后迁移到 schema 4；坏主档不会覆盖有效备份。导入、重置和接管先返回校园；异步读取结束后也复查阶段。设置里明确的 0、false 和静音继续保留。多页面沿用原写锁、主键和备份；未来 schema 不覆盖原文。可导出 / 导入本地 JSON；缺少持久能力时仍可内存游玩和导出。
